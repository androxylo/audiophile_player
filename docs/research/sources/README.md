# Local Research Sources (Browser-Captured PDFs — Gitignored)

Place browser-saved PDFs here whenever an investigation encounters a resource that the agent cannot access directly (paywalled papers, login-walled message board threads, Cloudflare/anti-bot pages, or manuals).

**Copyright Rule:** `*.pdf` and downloaded third-party reference files inside this directory are **gitignored** so copyrighted articles, papers, forum snapshots, and any other restrictively copyrighted materials are never committed to this public repository. Only original summaries and citations are committed under `docs/research/`.
